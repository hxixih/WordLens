# 划词译 · WordLens

一个轻量的原生 macOS 划词翻译工具。选中文字，点击光标附近的「译」图标，即可通过你配置的 AI 模型翻译为简体中文。

支持网页、文本编辑器，以及通过复制兼容模式读取选区的 PDF 阅读器。使用 Objective-C 和 AppKit 开发，运行时只依赖 macOS 系统框架。

**当前版本：1.0.2 · 默认构建：Intel / x86_64 · 最低部署目标：macOS 10.15**

## 功能

- **划词入口**：选中文字后显示浮动图标，点击打开翻译窗口。
- **上下分区**：上方显示可编辑的原文，下方显示中文译文，两部分分别提供复制按钮。
- **自动与手动翻译**：默认打开选区后自动翻译，也支持按钮和 `⌘↩` 手动翻译。
- **自定义模型**：配置 Base URL、模型名称、API Key 和请求超时，支持 OpenAI 兼容的 Chat Completions 接口。
- **PDF 兼容模式**：直接读取失败时，点击备用图标后复制选区，并尽量还原原剪贴板。
- **快捷键与菜单栏**：支持 `⌥⌘T`、翻译剪贴板、暂停划词图标和菜单栏常驻。
- **请求控制**：支持取消、超时和常见接口错误提示，避免旧请求覆盖新文本。
- **钥匙串存储**：API Key 按接口地址分别保存至 macOS 钥匙串。

## 安装

在 [Releases](https://github.com/hxixih/WordLens/releases) 页面下载 Intel 应用压缩包。也可以按下方“从源码构建”自行编译。

1. 解压，将 `划词译.app` 移动到“应用程序”文件夹，或用户自己的 `~/Applications` 目录。
2. 双击打开应用。菜单栏会出现「译」，同时打开翻译窗口。
3. 点击“设置”，填写模型参数，点击“测试连接”，成功后保存。
4. 点击“开启辅助功能”，在“系统设置 → 隐私与安全性 → 辅助功能”中允许该应用。列表中没有应用时，点击 `+` 添加安装后的 `.app`。
5. 在其他应用中选取文字，松开鼠标，点击浮动「译」图标。

划词读取和复制兼容模式需要辅助功能授权；手动输入、粘贴和“翻译剪贴板”不依赖该权限。程序不需要屏幕录制权限。

默认构建采用本地临时签名，未经 Apple 开发者公证。若 macOS 阻止打开，可在 Finder 中右键应用选择“打开”，或到“系统设置 → 隐私与安全性”选择“仍要打开”。

**升级**：先从菜单栏退出旧版本，再替换同一位置的 `.app`。原有模型参数和钥匙串密钥可继续使用；如果辅助功能授权失效，请重新授权。

## 模型设置

| 设置项 | 说明 |
| --- | --- |
| AI Base URL | 服务商提供的接口地址，例如 `https://api.openai.com/v1`。自动追加 `/chat/completions`，也可直接填写完整接口地址。 |
| 模型名称 | 服务商提供的准确模型 ID；默认留空，由用户填写。 |
| API Key | 在应用中填写并保存到钥匙串，不需要修改源码或配置文件。 |
| 请求超时 | 10–180 秒，默认 60 秒。 |
| 自动翻译 | 控制打开所选文本后是否立即翻译，默认开启。 |
| PDF / 复制兼容模式 | 控制直接读取失败时的备用图标和复制读取，默认开启。 |

本机、局域网和远程地址均支持 **HTTP 与 HTTPS**。示例：

```text
https://api.openai.com/v1
https://api.example.com/compatible-mode/v1
http://192.168.1.20:8080/v1
http://127.0.0.1:11434/v1
```

本机 `localhost`、`127.0.0.1` 和 `::1` 接口允许 API Key 留空；非本机接口需要填写 API Key。HTTP 以明文传输请求，HTTPS 使用系统证书验证。

接口应支持 `POST /chat/completions`，接受 `model` 和 `messages`，并返回 `choices[0].message.content`。只提供其他协议的服务不能直接使用。调用和计费由用户选择的模型服务决定。

密钥按规范化后的完整接口地址保存。改变主机、路径或 HTTP / HTTPS 协议后，需要为新地址配置密钥；清空密钥并保存可删除当前地址的密钥。

## 使用方式

| 操作 | 行为 |
| --- | --- |
| 选中文字 → 点击「译」 | 读取所选文本并打开翻译窗口；默认自动翻译。 |
| `⌥⌘T` | 读取当前应用的所选文本；直接读取失败时可使用复制兼容模式。 |
| `⌘↩` | 在翻译窗口中手动翻译当前原文。 |
| “翻译剪贴板” | 读取已经复制的文字并打开翻译窗口。 |
| “取消” / `Esc` | 取消正在进行的翻译；`Esc` 也可隐藏浮动图标。 |
| 菜单栏 →“启用划词图标” | 开启或暂停自动显示浮动图标。 |
| 菜单栏 →“退出划词译” | 完整退出程序。关闭翻译窗口时程序仍在菜单栏运行。 |

原文和译文各自滚动，窗口可调整大小。编辑原文后，点击“翻译”重新生成译文；关闭翻译窗口会清除原文、译文及撤销记录。

### PDF 兼容模式

不同阅读器通过辅助功能提供选区的方式不同。程序先尝试所选文本、选区范围和文档子控件，并进行一次延迟重试。读取失败时，拖选或双击动作也可触发备用图标。

**仅划词不会执行复制。** 点击备用图标或使用所选文本快捷键后，程序才向原应用发送一次 `⌘C`，读取新复制的文字，然后尽量还原剪贴板。

复制前会备份剪贴板的所有可读条目和格式，最多 16 MB；复制没有产生新内容时，不会将剪贴板中的旧文字作为选区。切换应用、重新点击或按键会取消读取。剪贴板并发变化、延迟复制、格式无法备份或剪贴板管理器介入时，不能保证完整还原，可改用手动“翻译剪贴板”。

备用图标依赖拖选手势，此时尚未确认选区包含文字；拖动图片等操作也可能显示图标。关闭“PDF / 复制兼容模式”可禁用此备用方式。

## 数据处理与限制

- 仅在点击图标、使用翻译入口或测试连接时，文本才会发送至配置的模型接口；划词本身不会触发网络请求。
- 应用不保存翻译历史，也不主动输出原文、译文或密钥到日志。模型服务的数据处理方式由该服务决定。
- API Key 存储在系统钥匙串；普通偏好设置仅保存接口、模型名、超时和功能开关。
- 不包含 OCR。没有文字层且阅读器未提供 OCR 的扫描版 PDF，无法通过该流程读取文字。
- 每次原文最多接受 24,000 个 UTF-16 单元，超过时提示分段，不会静默截断原文。
- HTTP 重定向不会自动跟随，请填写最终接口地址；认证错误、限流、超时和译文被模型截断时会显示提示。
- 当前默认只构建 Intel 应用；Apple Silicon 运行及原生构建尚未完成验证。

## 从源码构建

需要 macOS、Apple Command Line Tools 和 Python 3。运行编译好的应用不需要 Python、Node.js、Xcode 或其他第三方运行时。

```bash
# 如果尚未安装编译工具
xcode-select --install

# 获取源码
git clone https://github.com/hxixih/WordLens.git
cd WordLens

# 构建与测试
bash build.sh
bash test.sh
```

构建结果为 `dist/划词译.app`，编译缓存和测试程序位于 `work/build/`。可以通过 `WORDLENS_BUILD_DIR` 指定其他缓存目录。

```bash
open "dist/划词译.app"
```

生成可用于 GitHub Releases 的下载包：

```bash
bash package_release.sh
```

脚本会构建并检查应用，生成 `dist/WordLens-v1.0.2-Intel.zip` 和对应的 SHA-256 校验文件。下载包包含应用、README 和许可证；源码通过 GitHub 仓库单独提供。

```text
Source/                     原生应用源码
  WLApp.m                   界面、菜单栏、快捷键和划词事件协调
  WLCore.m                  AI 接口、设置、钥匙串和辅助功能读取
  WLCompatibility.m         PDF 备用复制、剪贴板备份还原和手势判断
  MakeIcon.m                离屏生成应用图标
  main.m                    应用入口
Tests/                      模拟网络、复制和剪贴板测试
Info.plist                  应用元数据与网络配置
build.sh                    编译并临时签名应用
test.sh                     编译并运行测试
make_icns.py                将生成的 PNG 打包为 ICNS 图标
package_release.sh          构建并打包 Releases 下载文件
.github/                    自动构建测试配置与问题模板

```

`dist/`、`work/` 和本地凭据由 `.gitignore` 排除，不需要提交到源码仓库。

## 测试与兼容性

当前自动化测试 **118 项全部通过**：80 项核心测试覆盖接口与错误处理，38 项兼容性测试覆盖选区范围、复制失败时防止旧文本误读、剪贴板还原、切换应用、并发变化和取消。测试使用模拟对象，不调用真实模型、不发送真实按键，也不读写系统剪贴板或实际 API Key。

应用已在 Intel Mac、macOS 15.8.1 上完成实际使用验证，包含网页划词、PDF 复制兼容流程和翻译操作。不同浏览器、阅读器和系统版本的完整兼容性矩阵尚未建立。macOS 10.15 是部署目标，尚未在该系统上完成运行验证。

仓库提供 GitHub Actions 配置，使用 Intel macOS 环境构建和测试。工作流需要在上传仓库后运行，本地测试通过不代表远程 CI 已通过。
